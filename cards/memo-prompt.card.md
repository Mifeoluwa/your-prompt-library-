# Prompt Card - Memo Writing Prompt

## Prompt Name
Memo Writing Prompt

## Purpose
Generate professional business memos.

## Task Type
Writing

## Input
A topic for the memo.

## Output
A professional memo with:
- Title
- Purpose
- Background
- Recommendations
- Conclusion

## Strengths
- Clear structure
- Professional tone
- Easy to understand

## Limitations
- Depends on the quality of the user's input.
- Cannot invent missing facts.
